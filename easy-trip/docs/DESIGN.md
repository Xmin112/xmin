# Easy Trip — 设计规范

## 设计理念

**iOS 玻璃 + 手绘温度**

网站外壳用 iOS 风格的毛玻璃质感——通透、冷静、高级。但地图和路线内容用手绘风格——温暖、有人味、像旅行手账。冷感外壳框住手绘内核，反差本身就是记忆点。

## 字体

| 场景 | 字体 | 说明 |
|---|---|---|
| UI 标题 | `SF Pro Display` / 系统默认 | iOS 原生感——界面部分干净利落 |
| UI 正文 | `SF Pro Text` / 系统默认 | |

> 中文字体备选：站酷快乐体、方正静蕾体（手写感），实际加载用 Google Fonts 中支持中文手写体的方案

## iOS 玻璃质感规范

### 毛玻璃卡片

```css
/* 典型卡片 */
background: rgba(255, 255, 255, 0.72);
backdrop-filter: blur(20px) saturate(180%);
-webkit-backdrop-filter: blur(20px) saturate(180%);
border: 1px solid rgba(255, 255, 255, 0.6);
border-radius: 20px;
box-shadow: 0 4px 30px rgba(0, 0, 0, 0.06);
```

### 页面背景

- 柔和的渐变底色，不是纯白——参考 iOS 健康 App 的暖色渐变
- 聊天页背景：极淡的暖灰 `#F2F1F6`（iOS 系统背景色）

### 圆角体系

| 尺寸 | 用途 |
|---|---|
| 8px | 小按钮、标签 |
| 12px | 输入框、消息气泡 |
| 16px | 普通卡片 |
| 20px | 主卡片、路线卡片 |
| 24px+ | 大面板、弹窗 |

### 阴影

全部用低透明度、无明确方向的柔和阴影：
```
box-shadow: 0 4px 30px rgba(0,0,0,0.06);
```
不做硬阴影，保持通透感。

## 手绘路线图规范

### 底图风格

- 用 MapLibre GL 自定义样式，去掉所有默认地图的硬朗感
- 道路颜色：暖灰/米色系，不是标准的灰/白色
- 建筑底色：淡米色
- 绿地/公园：柔和的水彩绿
- 水体：浅浅的天空蓝
- 字体标注：隐藏或替换为手写风格

### POI 标记

- 不是标准大头针，是**手绘小图标**
- 咖啡店 = 小咖啡杯图标 ☕️（手绘风，不是 emoji）
- 化妆品店 = 小口红/面膜图标
- 服饰店 = 小衣架/购物袋图标
- 展览馆 = 小画框图标
- 每个图标像贴纸一样贴在底图上

### 路线线条

- 用 SVG 绘制，线条像是用荧光笔/记号笔画出来的
- 有轻微的不规则感和粗细变化（模拟手绘笔触）
- 颜色用珊瑚粉或芥末黄
- 起点终点有明显的手绘标记（小旗帜、小星星）

### 标注文字

- 手写体字体
- 用小箭头或虚线连接到对应位置
- 文案口语化："从 3 号口出来，右转就到啦 ✨"

### 整体排版

- 像一页手账——有边框装饰、小贴纸、手绘元素
- 四个角可以有胶带/贴纸的小装饰
- 底部可以有手写风格的日期、天气标注

## 交互规范

### 微交互

- 消息气泡：轻微弹入动画，像 iMessage 的出场感
- 按钮点击：iOS 风格的缩放反馈（按下缩小到 97%）
- 地图卡片展开：从聊天流中"浮出来"，配合毛玻璃模糊背景
- 选项按钮：hover 时轻微上浮 + 阴影加深
- 滚动：使用 iOS 风格的弹性滚动

### 加载状态

- AI 思考时：三个跳动的点（iMessage 风格），不是转圈
- 路线生成中：地图卡片区域显示柔和骨架屏 + 手绘铅笔图标动画
- 搜索中：小放大镜微动

## 分享卡片设计

用户点击"保存图片"后，Canvas 渲染一张独立的手账路线图，规格：

- 尺寸：750×1334（适合手机屏幕/社交媒体）
- 背景：奶油色纸张纹理
- 顶部：手写日期 + 城市名 + 今日天气小图标
- 中部：手绘地图 + 路线
- 底部：按顺序排列的地点列表，每个带序号、店名、一句话介绍、手绘小图标
- 角落：Easy Trip 小 logo + "和小伙伴一起去吧～"手写字样

这张图本身就是一个可传播的内容产品。
