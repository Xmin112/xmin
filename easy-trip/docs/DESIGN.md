# Easy Trip — 设计规范

## 设计理念

**暗调高级感 + 手绘温度**

参考 Linear、Vercel、Arc Browser 这些全球顶级产品的设计语言——暗色底、微妙玻璃质感、噪点纹理、字体即设计。但 Easy Trip 做的是旅行，不能像项目管理工具那样冷冰冰，所以用**温暖的 accent 色 + 手绘地图**来做反差。

一句话：用户打开网站觉得"这个产品好高级"，看到路线图觉得"这个好可爱想分享"。

## 暗色玻璃质感规范

### 毛玻璃面板

```css
/* 标准玻璃面板 — 微妙、不油腻 */
.glass-panel {
  background: rgba(255, 255, 255, 0.04);
  backdrop-filter: blur(16px);
  -webkit-backdrop-filter: blur(16px);
  border: 1px solid rgba(255, 255, 255, 0.08);
  border-radius: 16px;
}

/* 稍强一点的玻璃 — 用于悬浮卡片 */
.glass-elevated {
  background: rgba(255, 255, 255, 0.06);
  backdrop-filter: blur(20px);
  border: 1px solid rgba(255, 255, 255, 0.10);
}

/* 输入框玻璃 — 更深一点，暗示可交互 */
.glass-input {
  background: rgba(255, 255, 255, 0.06);
  backdrop-filter: blur(12px);
  border: 1px solid rgba(255, 255, 255, 0.10);
  border-radius: 14px;
}
```

### 噪点纹理

页面背景上加一层极 subtle 的 grain：

```css
.page-bg {
  background-color: #0A0A0B;
  /* 叠加 SVG 噪点纹理 */
  background-image: url("data:image/svg+xml,..."); /* 或 CSS noise filter */
}

/* 或用伪元素 + SVG filter 实现 */
.page-bg::before {
  content: '';
  position: fixed;
  inset: 0;
  opacity: 0.015;
  background-image: url('/noise.svg');
  pointer-events: none;
  z-index: 0;
}
```

噪点让暗色背景不再"空洞"，有纸张般的物理触感。Linear 就是这么做的。

### 圆角体系

| 尺寸 | 用途 |
|---|---|
| 6px | 小按钮、标签 |
| 10px | 输入框、消息气泡 |
| 14px | 常规卡片 |
| 18px | 主面板、玻璃卡片 |
| 24px | 大面板、路线图卡片 |
| 9999px | 药丸形按钮 |

### 光影

暗色模式下不用传统阴影，靠**亮度差**制造层次感：

```css
/* ❌ 不用：box-shadow 黑乎乎一片 */
/* ✅ 用：更亮的 border + 微妙的 glow */
.glass-elevated {
  border-color: rgba(255, 255, 255, 0.12);
  box-shadow: 0 0 0 1px rgba(255, 255, 255, 0.04),
              0 4px 20px rgba(0, 0, 0, 0.3);
}
```

## 手绘路线图规范

> 这部分保持不变——路线图是暗色 UI 中的亮色"内容岛"，反差本身就是设计。

### 底图风格

- MapLibre GL 自定义样式，彻底覆盖默认地图
- 道路：暖灰色系 `#E8E0D5`
- 建筑：淡米色 `#F0EBE3`
- 绿地/公园：水彩淡绿 `#D4E8CF`
- 水体：柔和蓝 `#C4DFE8`
- 去掉所有默认标注（路名、POI 标签）

### POI 标记

- 手绘风格 SVG 图标，按店铺类型区分
- 咖啡 ☕️ / 购物 🛍️ / 艺术 🎨 / 美食 🍽️ / 美妆 💄
- 图标像贴纸，带细细的白色描边，从底图上"浮"起来

### 路线线条

- SVG overlay，模拟荧光笔/记号笔笔触
- `stroke-linecap="round"` + `stroke-linejoin="round"`
- 轻微 `stroke-dasharray` 抖动感
- 颜色用珊瑚粉 `#FF6B6B`（跟品牌 accent 一致）
- 起点 ⭐ 终点 🏁 手绘标记

### 标注

- 手写体，小箭头连到位置
- 口语化文案："3号口出来右转 → 走2分钟就到啦～"

### 整体排版（路线卡片内部）

- 像一页旅行手账页
- 四角可点缀小装饰（胶带、贴纸、日期手写标注）
- 底部有时间轴式的地点列表

## 布局体系

### 主页面 — Bento Grid 双栏

```
┌──────────────────────────────────────────┐
│  ●●●  Easy Trip                      ⚙️  │  ← 顶部：品牌名 + 设置 icon
├──────────────────┬───────────────────────┤
│                  │                       │
│   聊天区 (60%)    │   地图预览区 (40%)     │
│                  │                       │
│  ┌────────────┐  │   ┌───────────────┐   │
│  │ AI 消息气泡  │  │   │               │   │
│  └────────────┘  │   │   实时地图      │   │
│  ┌────────────┐  │   │   + 路线预览    │   │
│  │ 选项卡片     │  │   │               │   │
│  │ 💄 👗 ☕ 🎨 │  │   │               │   │
│  └────────────┘  │   └───────────────┘   │
│  ┌────────────┐  │                       │
│  │ 用户消息    │  │   ┌───────────────┐   │
│  └────────────┘  │   │ 路线卡片(展开)  │   │
│                  │   │ [手绘地图大图]  │   │
│                  │   └───────────────┘   │
├──────────────────┴───────────────────────┤
│  ┌──────────────────────────────┐  ▶️    │  ← 底部输入栏
│  │ 💬 说说你的旅行想法...          │       │
│  └──────────────────────────────┘       │
└──────────────────────────────────────────┘
```

- 桌面端：左右分栏，聊天 + 地图实时同步
- 平板/手机：单栏，聊天全宽，地图卡片嵌入聊天流中
- 布局用 CSS Grid bento 风格，不是生硬的 50/50

### 响应式断点

| 断点 | 布局 |
|---|---|
| ≥1024px | 双栏：左聊天 60% + 右地图 40% |
| 640-1023px | 双栏但地图缩小，聊天占 65% |
| <640px | 单栏堆叠，地图嵌入聊天流 |

## 交互规范

### 微交互

| 场景 | 效果 |
|---|---|
| 消息气泡出现 | `opacity 0→1` + `translateY(8px→0)`，spring 缓动 |
| 选项卡片 hover | 亮度提升 + `scale(1.02)` + border 变亮 |
| 按钮点击 | `scale(0.97)` 瞬间缩放反馈 |
| 路线卡片展开 | 从聊天中"pop"出来，配合 backdrop 模糊加深 |
| AI 思考中 | 三个点跳动（不是转圈），颜色用 accent 紫 |
| 路线生成中 | 地图区柔和脉冲光 + 铅笔 icon 微微抖动 |
| 页面滚动 | 惯性滚动，`scroll-behavior: smooth` |

### 过渡动画

```css
/* 全局过渡基调 */
* {
  transition: all 0.2s cubic-bezier(0.4, 0, 0.2, 1);
}

/* 消息入场 */
@keyframes message-in {
  from { opacity: 0; transform: translateY(8px); }
  to   { opacity: 1; transform: translateY(0); }
}
```
