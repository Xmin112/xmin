# Easy Trip — 前端设计提示词

> 基于 Vita Architecture / KidSuper World / Mirofish 三个参考站拆解后生成的完整设计方向

---

## 一、画面风格

### 1.1 整体基调
- **主色调**：暖白底 `#F5F0EC`，不是纯白——有纸张的微微泛黄温度
- **副色**：深棕 `#2D221E`（文字）、暖灰 `#B8A99A`（辅助）
- **Accent**：珊瑚粉 `#FF6B6B`（品牌唯一跳跃色）、iOS 蓝 `#007AFF`（交互）
- **文字色**：一级 `#2D221E`、二级 `#8B7E74`、三级 `#B8A99A`

### 1.2 质感
- **玻璃**：白色半透明 `bg-white/60` + `backdrop-blur-2xl` + 1px 淡黑边框
- **卡片**：圆角 16-20px、极淡阴影 `shadow-sm`
- **底纹**：微妙纸张纹理（可选 SVG noise overlay）
- **地球**：奶油色底球体 + 浅色大陆块 + 柔和光晕，像一颗精致的陶瓷地球仪

### 1.3 图形元素
- 不要抽象的装饰图形
- 地球本身就是核心视觉元素
- 地图上的 POI 用手绘 emoji 风格小图标
- 路线用珊瑚粉手绘感线条

## 二、字体排印

| 层级 | 字体 | 大小 | 字重 | 用途 |
|---|---|---|---|---|
| Hero | Inter / SF Pro Display | 56-96px | 700 | 首页品牌大标题 |
| 标题 | Inter | 20-28px | 600 | 区块标题 |
| 正文 | Inter | 15px | 400 | 聊天消息、描述 |
| 辅助 | Inter | 12-13px | 400 | 时间戳、标签 |
| 特色 | 手写体 (Caveat/ZCOOL) | — | — | 路线图标注 |

- 行高：1.5-1.6（正文）、1.2（标题）
- 字母间距：标题 `-0.02em`、标签大写 `0.2em`
- 断开式标题排列（参考 Vita 的诗意分行）

## 三、布局系统

### 3.1 首页（Landing）
```
┌──────────────────────────────────────┐
│                                      │
│          [3D 地球 — 缓慢自转]         │
│                                      │
│        AI Travel Planner             │  ← 小标签
│        Easy Trip                     │  ← 大标题
│                                      │
│        [ 开始旅程 ]                   │  ← 深色药丸按钮
│                                      │
│    告诉 AI 你想去哪，它帮你规划路线    │
│                                      │

```
- 地球占满屏，文字层叠在地球上方
- 底部渐变遮罩过渡到背景色
- 点击按钮 → 地球放大 + 模糊 → 飞入聊天页

│                      │               │
│   用户: 首尔弘大      │               │
│                      │               │
│   AI: [选项卡片]      │               │
│   💄  👗  ☕  🎨     │               │
│                      │               │

- 桌面端 58:42 分栏
- 聊天区有独立滚动
- 右栏地球/地图始终可见
- AI 路线输出时地球飞到对应位置

### 3.3 移动端
- 单栏布局，地球缩小嵌入聊天顶部
- 全屏手势友好

## 四、交互动效

### 4.1 页面级过渡

| 过渡 | 时长 | 缓动 | 描述 |
|---|---|---|---|
| 首页→聊天 | 2000ms | cubic-bezier(0.25,0.1,0.25,1) | 地球放大 3x + 模糊 + 淡出 |
| 聊天内容淡入 | 700ms | ease-out | 延迟 200ms，文字+界面同时出现 |

### 4.2 微交互

| 元素 | 效果 | 时长 |
|---|---|---|
| 开始按钮 hover | 背景色从白渐变到彩虹 + "Let's Go" 文字 | 500ms |
| 开始按钮 active | scale(0.95) | 100ms |
| 消息气泡入场 | opacity 0→1 + translateY(12→0) | 350ms |
| 选项卡片 hover | scale(1.02) + 阴影加深 | 300ms |
| 选项卡片 active | scale(0.98) | 100ms |
| 发送按钮 | active scale(0.9) + 弹簧回弹 | 200ms |
| AI 思考中 | 三个小圆点依次弹跳 | 无限循环 |
| 地球飞到目的地 | 相机 smooth lerp + easeInOutQuad | 1600ms |
| 导航返回按钮 hover | 背景从 5% 黑 → 10% 黑 | 200ms |

### 4.3 滚动行为
- 聊天区：平滑惯性滚动
- 自定义滚动条（4px 宽、圆角、半透明）
- 移动端弹性滚动

## 五、交互逻辑

### 5.1 首页 → 聊天
1. 用户看到地球 + 标题
2. 点击"开始旅程"
3. 地球放大 3 倍虚化淡出（portal 式"被吸进去"的感觉）
4. 2 秒后聊天页淡入
5. AI 先打招呼

### 5.2 聊天流程
1. AI 主动问目的地
2. 用户回复 → 消息气泡弹入
3. AI "正在搜索..."（三点跳动）
4. AI 回复 + 选项卡片出现
5. 用户点击选项或打字回复
6. 重复直到 AI 输出路线
7. 路线卡片出现在聊天流中
8. 右侧地图/地球同步更新

### 5.3 返回首页
- 点击左上角 ← 按钮
- 回到首页地球

## 六、技术栈

| 层 | 技术 | 理由 |
|---|---|---|
| 框架 | Next.js 16 (App Router) | SSR + 路由 |
| 语言 | TypeScript strict | 类型安全 |
| 样式 | Tailwind CSS 4 + 自定义 CSS | 原子化 + 灵活 |
| 3D | React Three Fiber + @react-three/drei | 地球渲染 |
| 地图 | MapLibre GL | 路线可视化 |
| 动画 | CSS transitions + requestAnimationFrame | 轻量，不引入 GSAP 依赖 |
| AI | DeepSeek V4 Pro API | 对话 + 路线规划 |
| 字体 | Inter (Google Fonts) | 现代无衬线 |

## 七、设计原则（不可妥协）

1. **留白是奢侈** — 参考 Vita，不要让任何元素挤到没有呼吸空间
2. **一个页面一个焦点** — 首页就是地球，聊天页就是对话，别塞太多东西
3. **动画要有重量感** — 不是轻飘飘的淡入，是有物理惯性的过渡
4. **温暖但不幼稚** — 暖色调、手绘地图，但整体保持成年人的审美
5. **每次交互都有反馈** — 按下、hover、加载、完成，每个状态都有视觉回应
6. **文字即设计** — 排版质量和文字选择跟图形一样重要
