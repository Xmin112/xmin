# Easy Trip — 产品需求文档

## 产品定位

**AI 旅行路线顾问**——用对话的方式帮你规划一天或几天的行程，输出高颜值的手绘风格路线图，让旅行计划变成可分享的内容。

一句话：你告诉 AI 想去哪玩、喜欢什么调性，它帮你搜罗好地方、串成不走回头路的路线，最后给你一张好看得想发朋友圈的路线图。

---

## 目标用户

| 用户类型 | 特征 | 场景 |
|---|---|---|
| 攻略懒人 | 不想花几小时翻小红书/大众点评 | "明天去圣水洞，帮我排一下" |
| 自由行新手 | 对目的地不熟，怕走冤枉路 | "首尔三天，热门区域怎么分配？" |
| 社交分享型 | 旅行要发朋友圈/小红书 | 路线图本身就很能打，直接截图分享 |
| 探店达人 | 有自己指定的店，也要 AI 推荐 | "圣水洞这 3 家我必须去，再帮我加几个好逛的" |

## 核心功能（MVP）

### F1：AI 对话式路线规划（单日）

**用户流程：**
1. 打开网页 → 看到 AI 对话界面
2. AI："嘿！今天想去哪儿玩？"
3. 用户："首尔圣水洞"
4. AI："想在圣水洞逛什么类型的？"
   - 化妆品/护肤路线 💄
   - 买衣服/设计师店 👗
   - 咖啡甜品吃吃吃 ☕
   - 看展/艺术馆 🎨
   - 随便晃晃，啥都想来点 ✨
   - 或者你自己说...
5. 用户选择/输入后，AI 联网搜索该区域当下最热门的相关店铺
6. AI 按地理位置排出一条不走回头路的步行路线
7. 用户可以追加："我还有个指定的店叫 XXX，帮我加进去"
8. AI 重新调整路线，输出最终方案

**AI 输出内容：**
- 📝 文字版行程（从哪个地铁口出 → 第 1 站 → 第 2 站 → ... → 结束）
- 📍 每家店的名、简短介绍（为什么值得去）
- 🗺️ 手账风格平面路线图（可保存/分享）

### F2：多日行程规划

**用户流程：**
1. 用户："我 6 月 10-12 号在首尔，帮我安排三天路线"
2. AI 联网搜索首尔当前最热门的区域和打卡点
3. AI 按区域就近原则分组：
   - Day 1：圣水洞 + 东大门（挨着近）
   - Day 2：弘大 + 延南洞
   - Day 3：景福宫 + 北村 + 仁寺洞
4. 每天各一条不走回头路的路线
5. 用户可以跟 AI 对话调整（"第二天不想去弘大，换成梨泰院"）
6. 输出完整三天行程 + 每天一张路线图

### F3：对话式偏好挖掘

AI 在聊天中会主动搞清楚这些事：
- 目的地和日期
- 出行人数/关系（一个人、情侣、闺蜜团？）
- 体力接受度（能走很多路吗？还是休闲为主？）
- 预算偏好（网红贵店 OK 还是性价比优先？）
- 有没有指定必去的店
- 什么绝对不能有（比如讨厌排队、不吃辣）

不是一次问完，是像朋友聊天一样自然地问。

## 版本规划

### MVP（现在做）

核心闭环：**打开网页 → 跟 AI 聊天 → 得到路线 → 拿到好看的地图**

| 优先级 | 功能 | 说明 |
|---|---|---|
| P0 | AI 对话式单日路线规划 | 核心中的核心 |
| P0 | 手绘风格路线图渲染 + 保存 | 传播力的来源 |
| P1 | 多日行程规划 | 单日跑通后立即做 |
| P1 | 对话式偏好挖掘 | 让 AI 更懂用户 |
| P2 | 暗色/亮色主题切换 | 先只做暗色 |

### 后续可扩展（架构预留）

这些不在 MVP 里，但架构已经留了口子：

- **账号系统** — 用户想保存历史行程、跨设备同步时加
- **行程收藏 & 管理** — 自然而然的需求
- **分享社区** — 路线图本身能打，公开分享 → 自然增长
- **多人协作规划** — 闺蜜/情侣一起排行程
- **打印/导出** — PDF 手账版、A4 打印版
- **多语言** — 中文先跑通，后面加英日韩
- **天气感知** — 根据天气预报调整建议（下雨天推荐室内）
- **实时交通** — 结合实时路况调整时间预估
- **移动 App** — Web 先验证，产品成熟了再做原生

## 成功指标（MVP）

| 指标 | 含义 |
|---|---|
| AI 能完成一次完整对话并输出路线 | 核心闭环 |
| 用户愿意截图分享路线图 | 传播力验证 |
| 单次规划耗时 < 30 秒 | 体验过关 |
| 用户回头看/二次使用 | 留存验证 |
