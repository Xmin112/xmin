# Voyage — 设计方向

## 参考产品分析

### Apple Maps
| 维度 | 分析 |
|---|---|
| **视觉语言** | 地图本身是主角。UI 浮在地图上，不遮挡。玻璃面板 + 圆角卡片 + SF 字体 |
| **交互逻辑** | 搜索→选点→路线→导航，每一步都精确。过渡流畅，不跳页 |
| **动效设计** | 地图缩放平滑，卡片从底部滑入，路线渐绘。所有动效都有物理惯性 |
| **排版规则** | 大标题用 SF Display Bold，正文用 SF Pro Text。字号层级严格。留白充裕 |
| **用户心理** | "我在用 Apple 的产品"——信任感、品质感、不焦虑 |

### Google Earth
| 维度 | 分析 |
|---|---|
| **视觉语言** | 卫星纹理 + 3D 地形。从太空到街角的缩放是核心体验 |
| **交互逻辑** | 搜索→飞行动画→到达。飞行过程本身就是产品价值 |
| **动效设计** | 飞行动画是 Google Earth 的灵魂。相机平滑推进，让人感觉真的在飞 |
| **排版规则** | 信息面板极简，不抢地图的视觉 |
| **用户心理** | "地球好美"→"我要看看我家"→"这里是什么地方"——探索欲驱动 |

### Apple Vision Pro
| 维度 | 分析 |
|---|---|
| **视觉语言** | 玻璃材质（glass material）——半透明、微反射、深度感。UI 浮在空间中 |
| **交互逻辑** | 眼动+手势。UI 元素对注视有微反馈。空间深度让界面有层次 |
| **动效设计** | 元素从空间中浮现，缩放有空间感。不是平面动画，是空间中的动画 |
| **排版规则** | 极简。极少文字。圆角。SF 字体。亮暗自适应 |
| **用户心理** | "未来已经来了"——空间计算带来的新奇感和沉浸感 |

### Airbnb
| 维度 | 分析 |
|---|---|
| **视觉语言** | 大图驱动。温暖色调。圆角卡片。Categories 用图标+文字横滑 |
| **交互逻辑** | 搜索→浏览→详情→预订。Categories 是亮点——一眼看懂"住什么类型" |
| **动效设计** | 卡片 hover 浮起、页面过渡流畅、图片懒加载淡入 |
| **排版规则** | Cereal 字体（自家定制）。大号标题 + 大量留白。信息密度低 |
| **用户心理** | "我想去这里住"——向往感、信任感、便捷感 |

### Arc Browser
| 维度 | 分析 |
|---|---|
| **视觉语言** | 极简到几乎没有 UI。侧边栏是唯一的界面元素。色彩来自网页内容本身 |
| **交互逻辑** | Command+T → 输入 → 打开。没有多余的步骤 |
| **动效设计** | 切换空间时平滑推拉。新标签打开有轻微弹跳 |
| **排版规则** | Inter 字体。极小字号。让内容成为主角 |
| **用户心理** | "这不是浏览器"——重新定义已有品类，产品感极强 |

### vitaarchitecture.com
| 维度 | 分析 |
|---|---|
| **视觉语言** | 建筑摄影驱动。纯白底。极简导航。项目轮播 |
| **交互逻辑** | 横向滑动轮播。点击进入项目详情 |
| **动效设计** | 平滑轮播。hover 图片微缩放 |
| **排版规则** | 无衬线体。项目名大写加粗。地址小写灰色 |
| **用户心理** | "这个工作室很专业"——极简传递品质感 |

### kidsuper.world
| 维度 | 分析 |
|---|---|
| **视觉语言** | 3D 沉浸空间。粉彩碰撞色。手绘元素。VHS 噪点视频 |
| **交互逻辑** | Portal 式场景穿越。点击"进入店铺"→走进 3D 场景→浏览商品 |
| **动效设计** | GSAP 驱动。拼贴风格动画。过冲缓动。视差层叠 |
| **排版规则** | 紧凑怪诞标题 + 手写便利贴标签 |
| **用户心理** | "这不是电商网站，这是一个艺术装置"——品牌性格爆炸式呈现 |

### mirofish-demo.pages.dev
| 维度 | 分析 |
|---|---|
| **视觉语言** | 全屏 3D 地球。粒子点云。发光标记点。深色背景 |
| **交互逻辑** | 地球可旋转。点击标记点定位。数据可视化 |
| **动效设计** | 地球自转。标记点弹入。相机飞行动画 |
| **排版规则** | 极简。信息在标记点弹出 |
| **用户心理** | "地球原来是数据仪表盘"——把熟悉的东西变成新体验 |

## 四条线的交集 → Voyage 设计方向

```
Apple Maps 的地图即产品、玻璃 UI、克制排版
    +
Google Earth 的飞行缩放、探索感
    +
Apple Vision Pro 的玻璃材质、空间深度、光与影
    +
Airbnb 的 Categories 卡片、向往感
    +
Arc 的极简、产品感
    +
KidSuper 的沉浸式"进入一个世界"
    +
Monument Valley 的 2.5D 等距、温柔几何
```

## Voyage 视觉系统

### 色彩

```
基调：纯白空间
  bg-primary:    #FFFFFF   页面底色
  bg-secondary:  #F5F5F7   Apple 标准浅灰底
  bg-glass:      rgba(255,255,255,0.55)   毛玻璃卡片

文字：
  text-primary:   #1D1D1F   Apple 标准黑
  text-secondary: #86868B   次级灰
  text-tertiary:  #AEAEB2   辅助灰

Accent（根据目的地动态切换）：
  默认    #007AFF   Apple 蓝
  首尔    #FF5E7A   珊瑚粉（韩国审美偏暖粉）
  东京    #E8394A   日本红
  巴黎    #2D5BFF   法国蓝
  曼谷    #F0A500   泰国金
  纽约    #4B6EF7   美式蓝

功能色：
  路线    金色渐变    #F5A623 → #FFD93D
  起点    星标        #FFD93D
  终点    旗标        accent 色
  光斑    accent 色   opacity 0.15-0.25, blur 80-100px
```

### 字体

```
品牌/大标题：  SF Pro Display (Inter 备选)
              字号 32-56px, weight 600-700
              字间距 -0.03em

正文/UI：      SF Pro Text (Inter 备选)
              字号 15-17px, weight 400-500

问题文字：      17-20px, weight 500, 居中

选项文字：      15px, weight 400

时间轴标题：    17px, weight 600

时间轴正文：    14px, weight 400

数字/时间：     SF Mono / JetBrains Mono
              12px, weight 400, tabular-nums
```

### 材质

```
地球：
  meshPhysicalMaterial
  roughness: 0.35
  metalness: 0.05
  clearcoat: 0.1
  transparent: true, opacity: 0.92
  → 效果：磨砂玻璃，微微透光，有反射但不过度

UI 面板：
  bg-white/55 + backdrop-blur-2xl
  border: 1px solid rgba(0,0,0,0.06)
  border-radius: 20-24px
  → 效果：浮在世界上方，不遮挡，只暗示边界

建筑几何体：
  meshStandardMaterial
  color: #F0F0F5
  roughness: 0.6
  → 效果：白色磨砂建筑块，柔和阴影

阴影：
  全部使用柔和阴影
  box-shadow: 0 4px 20px rgba(0,0,0,0.06)
  不做硬阴影，不做弥散大阴影
```

### 空间深度

```
层级结构（从前到后）：
  Layer 5  光标 / 输入框           active 状态
  Layer 4  弹出卡片 / Tooltip      悬浮层
  Layer 3  UI 面板（玻璃）         交互层
  Layer 2  光斑 / 氛围             装饰层
  Layer 1  地球 / 2.5D 世界        内容层
  Layer 0  纯白背景                基底
```

### 2.5D 世界设计

```
不是真实地图，是有风格的"玩具城市"。

建筑：
  - 白色几何块（可能是圆角立方体）
  - 等距视角（固定 30-45° 俯角）
  - 柔和定向光（模拟下午 3 点的光线）
  - 地面是柔和的米色/灰色平面
  - 道路是比地面稍深的灰色细线

路线：
  - 金色虚线串联地点
  - 起点 = 金色星星
  - 终点 = accent 色旗帜
  - 选中地点 = 建筑微浮起 + 发光描边

氛围：
  - 体积光从右上角打下来
  - 光斑颜色根据目的地切换
  - 像在一个精致的沙盘模型里
```

### 动效时间线

```
0ms    页面加载，地球出现，开始自转
3000ms  "你想去哪？" 淡入 (opacity + translateY, 600ms)
        ↓
用户输入 "首尔" → Enter
        ↓
0ms    答案文字上浮消失 (400ms)
400ms   "和谁一起去？" 淡入 (400ms)
        ↓
用户输入 "一个人" → Enter
        ↓
0ms    答案上浮消失 (400ms)
400ms   选项卡片淡入 (400ms, staggered 每个延迟 80ms)
        ↓
用户选择 "☕ 咖啡探店"
        ↓
0ms    选中卡片微放大 + 其余淡出 (350ms)
500ms   "正在为你探索首尔..." 淡入
1500ms  文字淡出，地球开始缩放
        ↓ 飞行 4 级 (共约 8s)
        ↓
0ms    到达目标区域
300ms  2.5D 建筑群依次弹出 (每个 80ms stagger)
500ms  路线金色虚线渐绘 (800ms, 从左到右)
800ms  时间轴卡片从左侧滑入 (stagger 100ms)
```

## 禁止的设计模式

- ❌ 奶油色/米黄色背景
- ❌ 抽象椭圆装饰（blob）
- ❌ Dribbble 风格渐变色卡片
- ❌ 大面积的渐变背景
- ❌ 概念艺术网站式的炫技动画
- ❌ 无意义的装饰元素
- ❌ 过度的阴影和发光
- ❌ AI 生成的"模板感"排版
- ❌ 假数据填充的设计稿

## 追求的设计品质

- ✅ 每一个像素都是有意义的
- ✅ 动画有物理惯性，不飘
- ✅ 留白是设计语言的一部分
- ✅ 信息在需要时精确出现
- ✅ 颜色克制但精准
- ✅ 字体大小层级清晰
- ✅ 交互反馈即时且微妙
- ✅ 看起来像 Apple 做的旅行产品
