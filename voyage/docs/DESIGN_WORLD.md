# Voyage World — 设计系统

## 审美方向

**"温暖的手工微缩模型世界"** —— 像有人用木头、纸板、毛毡手工搭建的一座微型城市。

不是数字世界。不是科幻世界。是**手作感的世界**。

参考：Animal Crossing 的玩具感 + Monument Valley 的几何诗意 + 日式微缩模型的精致

---

## 色彩

```
基底：
  地面        #F5EDE0   暖米色（像未漂白的纸）
  人行道      #EDE5D8   稍白
  路面        #E0D8C8   灰米

建筑：
  暖白系      #F8F2EA, #F3EDE3, #EDE6DA
  暖棕系      #D4B896, #C4A882, #B89878
  砖红系      #C8957A, #B8846A (POI 专属)

自然：
  树冠        #7BA869, #6B9659, #8DBB78
  树干        #A08060
  灌木        #8DBB78, #A0C890

点缀：
  珊瑚强调    #FF6B6B   按钮、标记、印章
  金色         #FFD93D   收集品、路线
  暖白文字    #FFFDF5   UI 底色

阴影：
  不在纯黑，在暖棕 #8B6B4A + 低透明度
```

## 字体

禁止 Inter, Roboto, Arial, system fonts。

```
UI 文字：    'Nunito', sans-serif (圆润、友好、游戏感)
手写标注：   'Caveat', cursive (路线图上的标注)
数字/数据：  'Nunito', tabular-nums
```

---

## 材质规则

**一切都有纹理。** 没有纯色平面。

| 表面 | 方式 |
|---|---|
| 地面 | 噪点纹理 + 微妙色彩变化（不同区域的米色有 1-3% 差异） |
| 建筑墙面 | 随机微色差，粗糙度 0.6-0.75 |
| 建筑屋顶 | 比墙面深 10-20%，粗糙度 0.5 |
| 树木 | 多个球体堆叠 + 粗糙度 0.6 |
| 角色 | 光滑（粗糙度 0.3），形成对比 |

---

## 光照

**黄金小时光** —— 下午 3:00-4:00 的温暖阳光。

```
方向光：    方位 135°, 仰角 50°, #FFE4CC, intensity 1.5
环境光：    #FFF5EC, intensity 0.55
半球光：    天空 #FFECD2 + 地面 #C8B898, intensity 0.5
色调映射：  ACESFilmic, exposure 1.1
```

## 空间规则

```
建筑间距：   3-5m (留出"小巷"感)
道路宽度：   2-3m (能走，但不宽)
建筑高度：   2-8m (2-5 层楼的玩具比例)
角色身高：   ~1m (约建筑的 1/3-1/5，像小孩在成人世界里)
树高：       2-3m (跟建筑差不多，但因为圆润所以可爱)
```

---

## UI 规则

**所有 UI 在世界内部，不在世界上面。**

- 不用 glass-panel HTML div
- 不用 fixed/absolute 定位对话框
- 地点信息 = 一个漂浮在建筑旁的 3D 小标签
- 探索计数 = 角落一个半透明的小徽章
- 印章获得 = 全屏但用 Canvas 渲染的粒子动画，不是 HTML 卡片

---

## 动效规则

```
世界入场：      建筑从地面依次"长出来"(0.5s/个, 30ms stagger)
角色走路：      Y 轴微弹跳 + 朝向旋转
点击反馈：      地面出现微小的涟漪（圆环扩散消失）
发现地点：      建筑顶部冒出小星星粒子
印章获得：      全屏金色粒子爆发 + 缓速落下
世界呼吸：      光的方向微摆(±2°)，阴影随之移动
```
