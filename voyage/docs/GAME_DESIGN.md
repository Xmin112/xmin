# Voyage — 游戏化探索机制

## 核心理念

Voyage 不是旅行规划工具。

Voyage 是一个**你可以住在里面的旅行世界**。

用户打开 Voyage 不是为了"规划一条路线"，而是为了"今天去看看首尔有什么好玩的"——即使他根本不打算去首尔。

就像有人天天打开动森不是为了"达成什么目标"，而是**那个世界本身值得待着**。

---

## 为什么用户会沉迷？

### 动森的答案

动森没有等级、没有 Boss、没有输赢。但玩家每天登录。

为什么？

因为**每天都有新的东西**：
- 今天商店进了什么新家具？
- 今天有没有新的昆虫？
- 今天哪个邻居在做什么？

因为**世界记得你**：
- 你种的树在长大
- 你修的桥昨天完工了
- 邻居会提到你三天前做过的事

因为**收集是一种本能**：
- 博物馆里还缺最后一只蝴蝶
- 家具套装集齐了 7/10
- 这个月的鱼就差一条

因为**没有压力**：
- 不想干活？躺岛上发呆也行
- 不想社交？一个人钓鱼也行
- 没有什么"必须做"，只有"想做"

---

### 星露谷的答案

星露谷看起来是种地游戏，实际上是**一套精密的满足感引擎**。

因为**每一小步都有反馈**：
- 种下一颗种子 → 浇水 → 几天后收获 → 卖掉 → 钱变多了
- 这个循环短的 3 天，长的 28 天，但每一步都看得到进展

因为**世界有自己的节奏**：
- 春天有春天的作物、鱼、节日
- 夏天有夏天的
- 错过要等一年——所以你会期待明年

因为**关系在生长**：
- 送礼物 → 好感度 +1 → 触发剧情 → 结婚
- 不是一次性的，是几个月（现实时间）的培养

---

### Cozy Grove 的答案

Cozy Grove 每天只给你 30 分钟的内容。

做完就没了。明天再来。

这个设计超级聪明——**它把"限制"变成了"期待"**。

你不会一口气玩完然后卸载。你会每天期待那 30 分钟。

---

## Voyage 的沉迷机制

### 1. 世界是活的

你打开 Voyage，看到的是**今天的首尔**。

不是"首尔的地图"，而是**此时此刻的首尔世界**。

- 也许是下午 3 点，阳光从西边照过来
- 也许今天是雨天，世界蒙上一层柔和的灰调
- 也许今天弘大那边在办一个快闪活动（限时内容）
- 也许圣水洞新开了一家咖啡馆（本周新内容）

**你明天再打开，世界不一样了。**

不是因为你换了目的地。而是因为**世界自己在变化**。

这种感觉就是：你会想打开看看"今天首尔什么样"——即使你今天不打算去首尔。

---

### 2. 你有一个小人在世界里

动森里最让人上瘾的不是钓鱼，不是装修。是**你的角色在那个世界里活着**。

Voyage 也需要一个小人。

不是那种 3A 大作的高精度角色。就是一个简单的小人——像动森那样可爱的几何小人，穿着你今天选的衣服。

- 你的小人站在圣水洞的街头
- 你点击 Tamburins，小人就**走过去**
- 小人走进店里，画面切到店内（一个小而美的场景）
- 小人"购买"了一个虚拟香氛蜡烛（收藏品 +1）

这个小人的存在让一切变得不同：
- 不是"我看了一下这家店的信息"
- 而是"我带我的小人去了这家店"

**情感连接发生在小人身上，不在你身上。**

---

### 3. 探索不是搜索

高德地图的逻辑：
> 输入目的地 → 搜索 → 结果列表 → 点一个 → 导航

Voyage 的逻辑：
> 打开世界 → 看到一片漂亮的城区 → "诶那边有个发光的东西" → 走过去 → 发现是一家隐藏的精品咖啡馆 → 收藏

**探索的本质是"不知道会找到什么"**。

如果每次打开都知道会看到什么，那就不是探索，是查询。

Voyage 需要：
- **迷雾/未发现区域**：没探索过的城区是灰色/朦胧的
- **随机惊喜**：每次打开世界，某些地点会"发光"——代表今天特别推荐
- **隐藏地点**：不是所有店都在地图上标出来的。有些要靠走进去才发现
- **当地人秘密**：完成某个区域的探索后，解锁一个"只有本地人才知道的店"

---

### 4. 收集驱动一切

人天生喜欢收集。

邮票、Pokémon、动森的鱼、星露谷的矿物——收集机制是游戏设计中最强大的驱动力。

Voyage 的收集系统：

#### 旅行印章（Travel Stamps）

每个城市有一组印章。每探索一个区域、发现一种类型的店铺、完成一条路线，获得一枚印章。

| 城市 | 印章总数 | 获取方式 |
|---|---|---|
| 首尔 | 24 枚 | 探索 8 个区域 + 发现 6 种店铺 + 完成 5 条主题路线 + 5 枚隐藏印章 |
| 东京 | 28 枚 | ... |
| 巴黎 | 20 枚 | ... |

**印章不是随便给的。每一枚都有对应的小插图（手绘或像素风），像真的旅游纪念章一样。**

集齐一座城市的全部印章 → 解锁这座城市的"黄金印章" + 特殊奖励（小人的限定服装/配饰）。

#### 记忆碎片（Memory Shards）

每次"去过"（在虚拟世界里探索过）一个地点，获得一片记忆碎片。碎片上有一小段文字 + 一张小插图。

把它们收集起来，就像一本旅行日记——但不是你写的，是世界帮你记录的。

#### 主题收藏（Collections）

不按城市，按主题：

- ☕ 全球咖啡馆 Collection（收集 50 个城市的咖啡馆打卡）
- 🎨 全球美术馆 Collection
- 🌸 全球赏花地点 Collection
- 🍜 全球街头美食 Collection

跨城市的收集让用户有"我想去更多城市看看"的动力。

---

### 5. 打卡 = 虚拟 + 真实双向流动

打卡有两种：

#### 虚拟打卡（在 Voyage 世界里）

你的小人走到一家店 → 打卡成功 → 获得印章 + 记忆碎片。

这个行为**完全在虚拟世界完成**。不需要你真的去首尔。

为什么有人会虚拟打卡？因为收集本身就好玩。因为印章好看。因为想集齐首尔全部 24 枚印章。

#### 真实打卡（你真的去了那个地方）

你在现实中走进 Tamburins 圣水旗舰店 → 打开 Voyage → 定位确认你在那里 → 真实打卡成功。

真实打卡的奖励是虚拟打卡的 3 倍。而且会获得**"真实到访"金光标记**——在印章旁边多一颗金色小星星。

**虚拟打卡让人想真实去。真实打卡让人想炫耀。**

这就是双向流动。Voyage 既是"去之前的期待"，也是"去之时的记录"，还是"去之后的纪念"。

---

### 6. 分享的不是路线，是"我的世界"

现在旅行 App 分享的是什么？

> "Day1 圣水洞→弘大，Day2 景福宫→北村"

这是一份行程表。没人想看行程表。

Voyage 分享的是什么？

> 一张图：你的小人站在首尔街头，身后是白色几何建筑群，金色的路线串联起你今天探索过的地点。角落有一枚印章在旋转——那是你刚集齐的"圣水洞咖啡骑士"勋章。

这不是行程表。这是**游戏截图**。

用户分享是因为：
- 印章好看，想炫耀
- 小人穿的新衣服可爱，想让人看
- "我发现了这家隐藏咖啡馆"——独家发现的满足感
- "我的首尔印章集齐了！"——成就感的社交表达

## 一个用户的 7 天循环

### Day 1 — 初遇
打开 Voyage → 看到一个漂亮的白色世界 → 地球在转 → "你想去哪？" → 输入"首尔" → 地球飞过去 → 小人出现在圣水洞街头。

她随便走了一圈，在 Tamburins 打卡（虚拟），获得第一枚印章。
"有点意思。"

### Day 2 — 再来看看
打开 → 发现圣水洞今天"发光"了——有限时活动："周末快闪集市"。
她的小人走进去，逛了一圈。获得了第二枚印章 + 一个集市限定的记忆碎片。
"明天还会有什么？"

### Day 3 — 开始收集
她发现"首尔印章"的总进度是 3/24。
好奇心被勾起来了。
"24 枚全部拿到会怎样？"
她今天故意去了之前没去过的两个区域，又获得 2 枚印章。

### Day 4 — 第一次分享
"首尔咖啡馆 Collection"集齐了 5/5——完成了一个主题收藏。
系统给了一个好看的动画 + 可分享的卡片。
她截图发到了小红书："我的首尔咖啡馆印章集齐了！"
朋友们问"这是什么 App？"

### Day 5 — 真实旅行前
她下周真的要去首尔了。
打开 Voyage → 切换到"旅行模式" → 系统把她收集过的地点自动生成了一条路线 → 小人沿着路线走了一遍（预览）。
"这个路线我熟悉了，到时候不会迷路。"

### Day 6 — 到了首尔
她在现实中走进 Tamburins。
打开 Voyage → 定位确认 → "真实到访"打卡成功。
印章旁边多了一颗金色星星。
"我真的来了。"

### Day 7 — 回到家
打开 Voyage → 她的首尔世界现在有了 6 枚"真实到访"标记。
她翻看之前的记忆碎片，像翻一本旅行日记。
"下次想去东京。"
她在地球上点了东京。小人出现在代官山。

---

## 总结：Voyage 不是工具，是地方

| | 传统旅行工具 | Voyage |
|---|---|---|
| 打开原因 | 需要规划路线 | 想看看今天的世界什么样 |
| 停留时间 | 用完就走 | 想待在里面 |
| 回访动力 | 下次旅行前 | 每天都有新东西 |
| 情感 | 效率、焦虑 | 期待、满足、宁静 |
| 分享 | 行程表 | 游戏截图 |
| 与真实世界关系 | 只有实用价值 | 虚拟探索 → 真实期待 → 真实到访 → 美好回忆 |
