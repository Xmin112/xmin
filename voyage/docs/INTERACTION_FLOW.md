# Voyage — 交互流程

## 交互模型

```
用户输入目的地
      │
      ▼
┌──────────────────┐
│  Apple Setup 式   │  问题→回答→淡出→下一个问题
│  渐进式问答        │  不是聊天，不是表单，是"对话空间"
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  地球飞行         │  World → Continent → Country → City → District
│  4 级缩放         │  每级停顿 2-3s，给用户"被运输"的体验
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  2.5D 世界展示    │  左侧时间轴 + 右侧等距城市
│  + 路线探索       │  联动交互，点击探索地点详情
└────────┬─────────┘
         │
         ▼
┌──────────────────┐
│  保存 / 分享      │  生成优美分享图 → 社交传播
└──────────────────┘
```

## 核心交互细节

### 1. 首页空闲态（IDLE）

- 纯白背景，全屏 3D 地球居中
- 地球材质：磨砂玻璃半透明 + 微反射
- 地球缓慢自转（Y 轴 ~0.06 rad/s）
- 体积光从右上方打下来，颜色为中性暖色
- **3 秒后**：文字"你想去哪？"从地球下方淡入（opacity 0→1, y 10→0）
- 同时下方出现一条极细的输入线（1px, #D1D1D6）

### 2. 问答流转（QUESTION_1 → 2 → 3）

每个问答的过渡：

```
[当前问题 + 用户答案]
        │
        ▼ 答案文字上浮 20px + opacity 0 (400ms)
[短暂空白 300ms]
        │
        ▼ 新问题文字下浮进入 (400ms)
[新问题 + 空白输入]
```

- 不保留历史对话。当前屏只有一个问题。
- 问题间有一个 6 段的进度条（不是数字，是细线）
- 每完成一步，进度条前进一格

### 3. 飞行缩放（FLYING）

4 级缩放，每级不同内容和停顿：

| 级别 | 相机距离 | 视角 | 持续时间 | 画面 |
|---|---|---|---|---|
| World | z=2.8 | 全局 | 入场已见 | 整个地球 |
| Continent | z=2.0 | 大洲 | 1.8s | 亚洲轮廓居中 |
| Country | z=1.5 | 国家 | 1.5s | 韩国/日本/法国... |
| City | z=1.15 | 城市 | 1.5s | 目标城市轮廓 |
| District | z=1.03 | 区域 | 1.2s | 2.5D 建筑群浮现 |

每级过渡：
- easeInOutCubic（加速→减速，丝滑）
- 相机同时平移+缩放，不是线性推进
- 地球自转在飞行开始时停止
- 每级到达后有 800ms 的微停顿（相机轻微呼吸摆动）

### 4. 探索态（EXPLORING）

双栏布局：
- 左栏（35%）：垂直时间轴
- 右栏（65%）：2.5D 等距世界视图

**时间轴交互：**
- 垂直排列的地点卡片
- 每个卡片：序号（大号） → 店名 → 一句话介绍 → 步行时间
- Hover：卡片微微右移 + 左侧出现 accent 色竖线
- Click：右侧世界视图飞到对应地点
- 滚动：独立滚动，不带动世界视图

**世界视图交互：**
- 2.5D 等距视角（类似 Monument Valley）
- 建筑是白色几何体块，带柔和阴影
- 路线是金色虚线，从起点星 → 各点 → 终点旗
- 当前选中地点：建筑微微浮起 + 发光描边
- Drag：可轻微旋转视角（±15°）
- Scroll：缩放（有限范围）
- Click 建筑：选中 + 弹出信息卡片

**联动逻辑：**
- 点时间轴 → 世界飞到对应点
- 点世界建筑 → 时间轴高亮对应项
- 两者始终保持同步

### 5. 分享态（SHARING）

点击"保存路线"：
- Canvas 渲染一张 750×1600 长图
- 内容：路线标题 → 2.5D 世界截图 → 时间轴 → "Made with Voyage"
- 下载 / 复制到剪贴板 / 直接分享

## 动效规范

| 类型 | 时长 | 缓动 | 场景 |
|---|---|---|---|
| 问题切换 | 400ms | easeInOutCubic | 问答流转 |
| 地球缩放 | 1.2-1.8s/级 | easeInOutCubic | 飞行 |
| 建筑浮现 | 500ms/个 | easeOutBack | 探索态入场 |
| 地点选中 | 350ms | easeOutCubic | 点击建筑 |
| 路线绘制 | 800ms | easeInOutCubic | 路线渐现 |
| 弹出卡片 | 300ms | spring(1, 0.8) | 信息弹窗 |
| 滚动 | — | 惯性 | 时间轴滚动 |

## 手势

| 手势 | 场景 | 行为 |
|---|---|---|
| 点击 | 建筑/时间轴项 | 选中 + 视角移动 |
| 拖拽（水平） | 世界视图 | 微旋转视角 ±15° |
| 滚轮 | 世界视图 | 缩放 0.8x-1.5x |
| 滚轮 | 时间轴 | 上下滚动 |
| 双击 | 世界视图 | 重置视角到默认 |
