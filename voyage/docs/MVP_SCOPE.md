# Voyage — MVP 范围定义

## MVP 目标

**证明核心体验闭环：** 用户输入目的地 → 地球飞到目标 → 看到一条可探索的路线 → 愿意分享。

不是功能完整的旅行产品，而是**一个让人"卧槽"的体验原型**。

---

## MVP 必做（P0）

### 1. 首页地球 + 问答流

**输入：** 无
**输出：** 全屏地球 + Apple Setup 式问答

- 纯白背景
- 磨砂玻璃材质地球，缓慢自转
- 3 秒后自动出现第一个问题"你想去哪？"
- 用户输入→下一个问题，共 3 个问题
- 最后一个问题用选项卡片（不用输入）
- 进度指示器（6 段细线，不是数字）

**验收标准：**
- 从进入网站到完成问答 < 20 秒
- 无闪烁，无页面跳转
- 在任何一步刷新页面都能回到该步（前端状态即可，不需要后端）

### 2. 地球飞行缩放

**输入：** 完成问答
**输出：** 地球缩放 + 镜头飞向目的地

- 5 级缩放：World → Continent → Country → City → District
- 每级过渡 1.2-1.8 秒，easeInOutCubic
- 最终停在目标区域上方
- 飞行过程中地球自转停止

**验收标准：**
- 缩放全程丝滑（60fps）
- 无突然跳变或闪烁
- 到达后有小停顿和微呼吸摆动

### 3. 2.5D 世界视图 + 时间轴

**输入：** 路线数据（至少 4 个地点）
**输出：** 左侧时间轴 + 右侧等距世界

- 2.5D 等距视角，建筑为几何白块
- 金色虚线路线串联地点
- 起点星标记，终点旗标记
- 时间轴列表：序号、店名、介绍、步行时间
- 点击时间轴 ↔ 世界视图联动

**MVP 数据方案：**
- P0：使用预制路线数据（3-5 个城市 × 2 条路线）
- P1：接入 DeepSeek API 动态生成
- 预制数据保证体验流畅，不依赖 AI 响应速度

**验收标准：**
- 路线清晰可见
- 联动交互流畅
- 建筑风格统一

### 4. 分享图生成

**输入：** 当前路线
**输出：** 一张可保存/分享的长图

- Canvas 渲染
- 包含：标题 → 世界截图 → 时间轴 → Logo
- 下载按钮

**验收标准：**
- 生成的图在手机上看清晰
- 有"Made with Voyage"品牌露出

## MVP 不做（P1/P2）

| 功能 | 原因 |
|---|---|
| AI 聊天对话 | Apple Setup 问答流替代聊天 |
| 用户注册/登录 | 无需账户即可完整体验 |
| 历史路线保存 | V2 加入 |
| 实时导航 | 不是导航产品 |
| 城市真实 3D 模型 | MVP 用几何建筑块（更有风格） |
| 多语言 | 先中文 |
| 移动原生 App | 响应式 Web 先验证 |
| 社区/分享广场 | V3 |
| 酒店/机票 | 不是 OTA |
| 打印版导出 | V2 |
| 天气信息 | V2 |
| 交通时间精确计算 | MVP 用直线距离估算 |

## MVP 预制数据

为保证演示体验，内置 3 条预制路线：

### 路线 A：首尔圣水洞咖啡之旅
- 4 个地点
- 地铁口：圣水站 3 号出口
- 总步行：约 15 分钟
- 风格：咖啡、甜品、小众店铺

### 路线 B：东京代官山逛街
- 4 个地点
- 地铁口：代官山站 正面口
- 总步行：约 20 分钟
- 风格：设计师店、书店、杂货

### 路线 C：巴黎玛黑区艺术探索
- 4 个地点
- 地铁口：Saint-Paul 站
- 总步行：约 18 分钟
- 风格：美术馆、买手店、咖啡馆

每条路线数据包括：
- 地点名、经纬度、类别、一句话介绍
- 地铁出口信息
- 步行距离和时间

## MVP 技术方案

| 层 | 技术 | 理由 |
|---|---|---|
| 框架 | Next.js 16 | SSR + App Router |
| 3D 地球 | React Three Fiber + Three.js | 地球渲染、相机动画 |
| 2.5D 世界 | Three.js（自定义场景） | 等距视角、建筑几何体 |
| 动画 | Framer Motion + GSAP | UI 过渡 + 复杂时间线 |
| 样式 | Tailwind CSS 4 + 自定义 CSS | 原子化 + 精细控制 |
| 地图底图 | MapLibre GL（仅 2.5D 参考） | 或直接用 Three.js 场景替代 |
| 分享图 | Canvas API | 前端渲染长图 |
| 路由 | Next.js App Router | 页面/步骤管理 |
| 部署 | Vercel | Zero-config |

---

## MVP 成功指标

| 指标 | 目标 |
|---|---|
| 核心流程完成率 | 90%+ 用户能走完问答→飞行→探索 |
| 飞行动画帧率 | 全程 55fps+ |
| 首次惊艳反应 | 内测用户 80%+ 在飞行阶段有正面情绪反应 |
| 分享图保存率 | 30%+ 完成探索的用户保存分享图 |
| 页面加载时间 | < 3 秒 (LCP) |
