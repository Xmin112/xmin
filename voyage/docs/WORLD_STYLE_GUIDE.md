# Voyage — 2.5D 世界风格指南

## 一句话定义

**一座城市的"玩具模型"——像从 Monument Valley 里走出来，又像 Google Earth 的等距艺术版。**

不是真实地图，不是卫星照片，不是 3D 扫描。是精心设计的、有风格的、让人想伸手触摸的微型世界。

---

## 参考视觉

### 一级参考（必须看）

**Monument Valley**
- 等距视角，不可能几何体
- 柔和的粉彩色块
- 建筑是"块"不是"楼"
- 阴影是设计元素，不是物理模拟
- 每个人看到第一反应都是"好美"

**Google Earth 缩放动画**
- 从太空到街道的推进感
- 每一级缩放都有新的细节浮现
- "发现"本身就是体验

**Apple Maps 卫星视图**
- 不是地图，是地球的俯视影像
- 建筑有体积感（轻度 3D 挤出）
- 颜色是自然的但经过了美化

### 二级参考（感受）

**Animal Crossing**
- 温暖的玩具世界
- 等距/俯视混合视角
- 树是圆球，房子是方盒子
- 一切都圆润、可爱但不幼稚

**SimCity (2013)**
- 建筑群有机排列
- 倾斜视角让城市有"模型感"
- 道路串联建筑，形成街区
- 光和影让城市像真实的沙盘

**Tiny Wings / Alto's Adventure**
- 极简几何世界
- 色彩渐变天空
- 前景是剪影，背景是光

## 视角系统

### 默认相机

```
俯角（pitch）：  -40°（从水平面往下 40 度）
旋转（yaw）：    25°（轻微偏右，不等距对称）
距离：          覆盖目标区域约 1.5km × 1km
类型：          正交投影（Orthographic）← 关键！
```

**为什么用正交投影？**
- 消除透视变形，建筑看起来更像"玩具"
- 距离感一致，所有建筑"平等"
- 跟 Monument Valley 一样的视觉语言
- 用户不会觉得"我在看地图"，而是"我在看模型"

### 视角约束

- 不允许自由旋转超过 ±20°
- 不允许缩放到"俯视平面"或"地面仰视"
- 始终保持在"45° 俯瞰一个沙盘"的范围内
- 给用户有限的探索自由度，但保持画面美感

## 建筑系统

### 建筑类型

| 类型 | 形状 | 尺寸范围 | 用途 |
|---|---|---|---|
| **塔楼** | 细高长方体 | 8×8×25m | 写字楼、酒店、大型商场 |
| **方块** | 正方体/矮长方体 | 6×6×10m | 咖啡店、餐厅、店铺 |
| **宽楼** | 宽扁长方体 | 15×8×6m | 美术馆、市场、百货 |
| **小屋** | 小正方体 | 3×3×5m | 独立小店、亭子 |
| **地标** | 特殊几何体 | 不等 | 塔、钟楼、特色建筑 |

### 建筑材质

```
材质类型：  MeshToonMaterial 或 MeshStandardMaterial + roughness 0.7
颜色：      #F2F0ED（暖白）~ #E8E5E0（微暖灰）
           每个建筑的白色有微妙差异（±3% 亮度），模拟手工涂装感
屋顶：      比墙面深 5-10%，微微偏暖灰
描边：      无
倒角：      所有建筑的边是圆角（bevel radius 0.3-0.5m）
           圆角让建筑看起来像塑料积木/陶瓷，不是真实的混凝土
```

### 建筑布局规则

```
1. 沿道路两侧排列，不是严格的网格
2. 建筑间距 2-4 米（模拟真实街道）
3. 高度有随机波动 ±15%，避免完全一致的天际线
4. 转角处建筑可以稍高（形成"街角地标"）
5. 目标地点（路线经过的店）：
   - 比其他建筑高 10-20%
   - 屋顶有 accent 色小标记
   - 选中时微微浮起 + 发光
6. 建筑不重叠，不穿模
```

### 建筑风格 — 按城市

| 城市 | 建筑特征 | 色彩偏移 | 特殊元素 |
|---|---|---|---|
| **首尔** | 细高塔楼+低矮店铺混合，密集排列 | 暖白偏粉 `#F5F0EC` | 小坡屋顶、窄巷 |
| **东京** | 紧凑方块，高度变化大 | 冷白偏灰 `#F0F0F3` | 细长建筑、小巷 |
| **巴黎** | 统一高度宽楼，整齐排列 | 暖白偏奶油 `#F5F2EB` | 斜屋顶、广场 |
| **曼谷** | 低矮宽楼+高塔楼对比 | 暖白偏金 `#F6F1E8` | 寺庙尖顶、运河 |
| **纽约** | 高塔楼为主，网格排列 | 冷灰白 `#EEEDF0` | 摩天楼、网格路 |

## 地面与道路

### 地面

```
类型：   平面（不是地形，没有山丘——MVP 阶段）
颜色：   #FAF9F6（几乎白，微暖）
材质：   无纹理，纯色 + 微妙噪点（模拟纸面/模型底座）
边缘：   地面边缘渐变淡出到白（不是硬切）
```

### 道路

```
类型：   细线，画在地面上
颜色：   #E5E2DC（比地面深一点点）
宽度：   主线 3-4m，支线 1.5-2m
交叉口： 微微加宽 + 圆角
描边：   无
```

### 特殊地面元素

```
绿地/公园：  柔和绿色块 #C8DCC8，圆角矩形
           树 = 深绿色小球体/椭球体 3-5m 高
           公园内建筑更少，留出"呼吸空间"

水体：      柔和蓝色块 #C8D8E8，圆角
           河流用弯曲的带状
           水面有极淡的光泽（shiny 微反射）

广场/空地：  比周围地面亮一点的矩形区域
           可能有小喷泉（蓝色小圆点）
```

## 路线系统

### 路线视觉

```
类型：   金色虚线
颜色：   主色 #F5A623，发光 #FFD93D
样式：   线段 8px + 间隔 4px
宽度：   在地面上 2m 宽
发光：   外层 4m 宽的柔和光晕，opacity 0.3
动画：   从左到右渐绘（stroke-dashoffset 动画）
```

### 起点与终点

```
起点：
  形状：金色五角星 ★
  大小：半径 3m
  颜色：#FFD93D
  动画：缓慢旋转 + 上下微浮动
  位置：最近的地铁站出口

终点：
  形状：小旗帜
  颜色：accent 色（跟随目的地）
  大小：旗杆 6m 高，旗面 2×1.5m
  动画：旗面微微飘动
```

### 途经点标记

```
形状：   实心圆点
大小：   半径 1.5m
颜色：   accent 色
上方：   白色数字（序号，字高 2m）
选中时： 圆点放大到 2m + 白色外发光环
```

## 光照系统

### 主光源

```
类型：     定向光 DirectionalLight
方向：     从右上到左下（模拟下午 2-3 点的阳光）
角度：     方位角 135°，仰角 50°
颜色：     暖白 #FFF8F0
强度：     1.0
投射阴影： 是（建筑在地面投下柔和阴影）
阴影颜色： #000000, opacity 0.15
阴影长度： 建筑高度的 1.5 倍
阴影柔软度：高（PCFSoftShadowMap）
```

### 环境光

```
类型：     AmbientLight
颜色：     #FFFFFF
强度：     0.6
作用：     让阴影部分不会太暗，保持"模型"的通透感
```

### 半球光（模拟天空+地面反射）

```
天空色：   #E8F0FF（冷白，微蓝）
地面色：   #FFF8F0（暖白，微黄）
强度：     0.4
```

### 体积光 / 氛围光

```
类型：     点光源 PointLight（多个）
位置：     建筑群上方 50m，散布
颜色：     accent 色
强度：     0.3
作用：     给建筑群染上微妙的色彩氛围
           颜色随目的地切换
```

### 建筑自发光（路线途经点）

```
选中建筑的屋顶/顶部：
  微微发光（emissive #FFFFFF, intensity 0.2）
  描一圈 accent 色光晕
  不是霓虹灯，是"被光照亮"的感觉
```

## 大气与氛围

### 天空

```
MVP：纯白背景。没有天空色，没有渐变。

原因：
  - 2.5D 世界的底面是白色/米色的"模型底座"
  - 上方也是白色——整个世界像是在一张白纸上
  - 这跟 Monument Valley 的"悬浮在空间中"的感觉一致
  - 强化"玩具模型"感，不是"真实世界"
```

### 雾气

```
远处建筑有极淡的白色雾
雾色：#FFFFFF
近处 0%，远处 15% opacity
让远处的建筑微微变淡，营造深度感
```

### 粒子

```
MVP：无粒子。
V2 可能加入：极淡的白色浮尘微粒（像阳光中的灰尘）
```

## 城市氛围 — 按时间

### 早晨模式（V2）

- 光从右边低角度打来，暖橘色
- 建筑投下长长的阴影
- 整体色温偏暖

### 午后模式（MVP 默认）

- 光从右上角 50° 打来，暖白
- 阴影适中
- 最清晰的"模型感"

### 傍晚模式（V2）

- 光从右边低角度，金橙色
- 建筑阴影变长
- 天空微微泛粉/橙
- 路线变成更亮的金色

## 2.5D 世界 vs 传统地图 对比

| | 传统地图 | Voyage 2.5D 世界 |
|---|---|---|
| 视角 | 俯视 90° | 等距 40-45° |
| 建筑 | 平面轮廓或灰色块 | 白色磨砂几何体 |
| 道路 | 彩色线条 | 灰色细线 |
| 氛围 | 信息密集 | 留白、呼吸感 |
| 情绪 | 实用、效率 | 好奇、探索 |
| 第一反应 | "这是一张地图" | "这是个模型城市" |
| 传播性 | 没人会截图地图 | 想截图分享 |
